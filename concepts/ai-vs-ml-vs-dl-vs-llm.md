# AI vs ML vs DL vs LLM

## Artificial Intelligence (AI)
AI refers to systems designed to perform tasks that appear intelligent.

Example:
- Voice assistants
- Recommendation systems
- Chatbots

---

## Machine Learning (ML)
ML is a subset of AI where systems learn patterns from data using algorithms.

Example:
- Spam detection
- Price prediction

---

## Deep Learning (DL)
DL is a subset of ML that uses neural networks with multiple layers.

Example:
- Image recognition
- Speech recognition

---

## Large Language Models (LLMs)
LLMs are deep learning models trained on massive amounts of text to predict the next token.

Example:
- ChatGPT
- Claude

Key limitation:
LLMs generate probable text, not verified facts.
